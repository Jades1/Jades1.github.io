Case citator

Example. A sample of published California cases. Each signal reflects the citing passages read when the sample was made, and is not a current check of any case.

A citator keeps one record per case, the relations between cases (who follows, distinguishes, or questions whom, with the citing passage quoted), and how far each case has been checked. Each case gets a signal computed from those relations and its place on a four-step ladder. Select a case to see who cites it and how.

  1. UncheckedThe case is on file with the holding relied on.
  2. Citers listedEvery case that cites it, from two public indexes.
  3. Citers screenedEvery published citer scanned for treatment language, flagged passages read and quoted.
  4. Checked on LexisA person runs Shepard's before each filing.
